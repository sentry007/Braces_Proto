# ⚡ Braces Reborn

> **The Modern Polyglot JSON Suite & Interactive Visual Schema Editor**

Braces Reborn is a high-performance, client-side developer workspace designed to format, validate, inspect, visually manipulate, and convert structured data across formats (JSON, XML, CSV, YAML, TOML, TOON) with live AI token cost optimization and one-click code generation (TypeScript, Zod, JSON Schema).

---

## ✨ Key Features

### 1. 🌲 Interactive Visual Tree & Drag-and-Drop AST Editor
- **Visual Reordering & Reparenting**: Drag and drop nodes or subtrees to reorder elements or reparent them into new parent structures with **zero risk of syntax errors** (no missed commas, unbalanced braces, or type errors).
- **Inline Key & Value Editing**: Double-click any key or value to edit in place.
- **Type Converter**: Switch node types on the fly (`string`, `number`, `boolean`, `null`, `object`, `array`).
- **Two-Way Synchronization**: Edits in the Visual Tree immediately update the Monaco Code Editor, and vice-versa.

### 2. 🔄 Bidirectional Polyglot Conversion Engine
Seamlessly convert structured data back and forth:
- **JSON ⇄ XML** (with automatic root wrapping and attribute preservation)
- **JSON ⇄ CSV** (with header detection and tabular mapping)
- **JSON ⇄ YAML** (with clean indentation and no references)
- **JSON ⇄ TOML** (with top-level object enforcement)
- **JSON ⇄ TOON** (Token-Oriented Object Notation for LLM context windows)

### 3. 🤖 AI & LLM Token Economy Suite
- **TOON Encoding**: Token-Oriented Object Notation saves **30%–60% of tokens** when passing large datasets and arrays to LLMs (Claude, GPT-4o, Gemini).
- **Live Token Counter**: Real-time token estimation comparing JSON, TOON, YAML, and Minified formats.
- **Smart Heuristic Auto-Repair**: Fixes dirty, truncated, or unquoted JSON payloads generated by LLMs and logs (converts single quotes, quotes keys, removes trailing commas, balances brackets).

### 4. ⚡ Code & Schema Generators
- **TypeScript Types & Interfaces**: Generates clean, strongly typed TypeScript interfaces from payload shapes.
- **Zod Schemas**: Produces `z.object({...})` validation schemas and inferred types.
- **JSON Schema**: Standard Draft 2020-12 schema generation.
- **Markdown Tables**: Converts payloads into clean Markdown tables ready for PR descriptions, Notion, and Slack.

### 5. 🛡️ 100% Client-Side Privacy
- **Zero Server Telemetry**: All parsing, transformation, and file handling happen 100% locally in your browser sandbox.
- **Safe for Confidential Data**: Securely handle proprietary API payloads, API keys, database dumps, and customer PII.

## 🚀 Getting Started

### Prerequisites
- **Node.js**: `v20+` or `v22+`
- **npm** or **pnpm**

### Installation & Development
```bash
# Clone the repository
git clone https://github.com/sentry007/Braces_Proto.git
cd Braces_Proto

# Install dependencies
npm install

# Start development server with HMR
npm run dev

# Build for production
npm run build

# Run linter
npm run lint
```
